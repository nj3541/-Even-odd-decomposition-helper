Even / Odd Decomposition

Enter discrete‑time samples x[n] to see even and odd parts.

Input sequence

Enter pairs n:x separated by commas. Example: -2:1, -1:0, 0:2, 1:0, 2:1

Results

Concept

  • Any signal can be written as x[n] = xe[n] + xo[n].
  • Even part: xe[n] = (x[n] + x[-n]) / 2.
  • Odd part: xo[n] = (x[n] - x[-n]) / 2.
